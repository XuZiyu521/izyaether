izyAether 隐私政策

更新日期：2026-10-19 · 开发者：徐子裕

引言

izyAether（以下简称"本应用"）由徐子裕开发和运营。我们深知个人信息对你的重要性，本政策说明本应用如何处理你的信息。概括来说：本应用不设账号、不收集个人信息、不内置广告和统计 SDK，你的数据只存在你自己的设备上。

一、我们处理哪些信息

1. 你主动录入的内容：Prompt / Skill、分类、标签、手动记账的余额、月度预算等，仅保存在本机。

2. API Key：你添加的厂商 API Key 使用系统密钥服务（HUKS）加密后保存在本机，界面只显示前后四位。

3. 本地资料：你在「我的」中填写的昵称、头像、简介、年龄、性别、属地均为选填，仅保存在本机，不上传。

4. 剪贴板：打开「锦囊」页或使用导入功能时，本应用会读取剪贴板内容，用于识别好友发来的分享码或待导入的文本。读取结果只在本机使用，不上传、不留存。

5. 图片：使用「图片识字」时，你选择的图片由系统端侧文字识别能力处理，图片和识别结果都不会离开设备。

二、联网说明

本应用只在以下情况联网，且均由你的操作触发：

1. 查询余额：对你添加了 API Key 的厂商（如 DeepSeek、月之暗面、智谱），本应用从你的设备直接向该厂商的官方接口发起查询。你的 API Key 只发送给对应厂商，不经过我们的任何服务器。

2. 价格数据更新：本应用可能从公开地址下载最新的模型价格表，该请求不包含任何个人信息。

3. 自动获取属地：仅在你在资料页选择「自动获取」后（之后打开资料页会静默刷新一次，可随时改为手选或不显示），向公开的 IP 属地查询服务（api.mir6.com、whois.pconline.com.cn、api.ip.sb）发起请求以推断省份。本应用不申请定位权限、不获取精确位置。

三、权限说明

本应用仅申请网络权限（用于上述联网场景）。通知用于余额预警、预算提醒和降价提醒，你可以随时在系统设置中关闭。选择图片、选择文件均通过系统选择器完成，本应用只能读取你选中的那一项。

四、信息的共享与传输

我们不会向任何第三方出售、共享或提供你的个人信息。分享功能（分享文本、长图、导出文件、发送到其他应用）均由你主动发起，经系统分享面板交给你选择的应用。

五、信息的存储与删除

你的数据保存在设备本地。你可以在应用内删除任意条目、清空回收站、删除 API Key；卸载本应用会删除全部数据。「完整备份」生成的文件由你自行决定保存位置，备份文件不包含 API Key。

六、未成年人保护

本应用面向一般用户，不针对未满 14 周岁的未成年人。若你是未成年人，请在监护人指导下使用。

七、政策更新与联系我们

本政策内容变更时，我们会在应用内重新提示你确认。如对本政策有任何疑问，请联系：cap41176985@163.com。

Overview

izyAether ("the app") is developed by 徐子裕. The app has no accounts, collects no personal information, and contains no ads or analytics SDKs. Your data stays on your device.

What the app handles

1. Content you enter (prompts, skills, categories, tags, manual balances, budgets) is stored only on this device.

2. API keys are encrypted with the system key service (HUKS) and stored locally; only the first and last four characters are shown.

3. Optional profile fields (nickname, avatar, bio, age, gender, region) are stored locally and never uploaded.

4. Clipboard: when you open the Library or use import, the app reads the clipboard to detect share codes or text to import. It is used on-device only.

5. Images used for text recognition are processed by on-device system capabilities and never leave the device.

Network use

The app goes online only when you trigger it: (1) balance queries are sent from your device directly to the official API of the vendor whose key you added; your key is never sent to our servers. (2) It may download a public price table that contains no personal data. (3) Only after you choose "Detect region" on the profile page (it then refreshes when that page opens; you can switch to manual or hidden at any time), it queries public IP-region services (api.mir6.com, whois.pconline.com.cn, api.ip.sb). No location permission is requested.

Permissions and sharing

The app requests only the network permission. Notifications are local and can be turned off in system settings. We never sell or share your information; sharing happens only when you start it via the system share sheet.

Storage, deletion and contact

Delete items, the trash or API keys at any time; uninstalling removes all data. Backups exclude API keys and are saved where you choose. Contact: cap41176985@163.com. Updated: 2026-10-19
